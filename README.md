# 🏏 IPL Data Analytics Dashboard

An interactive IPL analytics dashboard built using Python, Pandas, Plotly, and Streamlit.

## Features
- Team performance analysis
- Toss impact analysis
- Top run scorers
- Top wicket takers
- Highest scoring venues
- Interactive charts & filters

## Technologies Used
- Python
- Pandas
- Plotly
- Streamlit
- Seaborn
- Matplotlib

## Run Locally

```bash
streamlit run app.py
